# BunnyCode

**A desktop home for your AI coding agents.**

BunnyCode puts the coding agent you already use, such as Claude Code, OpenCode, Codex CLI, Gemini CLI or Qwen Code, inside a native app with a proper editor around it. You talk to the agent on one side and see what it changes right away: open files reload as the agent edits them, and the git view shows every change before you commit it.

You don't have to give up your editor to work with an agent, or keep juggling a terminal window, an editor and a git client.

## What's inside

- **Your agent, built in.** Run any agent that works in a terminal. Pick one in Settings or add your own.
- **A real code editor.** Syntax highlighting, autocomplete, error checking and go-to-definition for the common languages.
- **Git without the command line.** See what changed, stage, commit, push, pull, switch branches and resolve conflicts from the sidebar.
- **Two terminals.** One for the agent, one for you.
- **Open anything.** Work on a whole project folder or open a single file. You can also open files from Finder or Explorer, or from your terminal with the `bunnycode` command.
- **Search across your project.** Find text in every file, with filters when you need them.
- **Themes.** A set of built-in light and dark themes, and you can import your VS Code themes.
- **Work on another machine.** Run BunnyCode on a server and connect to it from your laptop.

## Where it runs

| Platform | Status | Download |
| --- | --- | --- |
| **macOS** (Apple Silicon) | Supported | `.dmg` |
| **Windows** (64-bit) | Supported | `.exe` installer or `.msi` |
| **Linux** | ⚠️ Experimental | `.deb` or `.AppImage` |

On Linux it works, but it gets less testing than on macOS and Windows, so expect rough edges.

## Getting it

1. Go to the [**Releases**](../../releases/latest) page.
2. Download the file for your system from the table above.
3. Install it the usual way for your system.

BunnyCode tells you when a new version is available. You can also check from **About → Check for Updates**.

> **macOS:** if macOS says it can't check the app for malicious software, right-click BunnyCode in Applications, choose **Open**, then confirm. You only need to do this once.

## Before you start

BunnyCode brings the window, not the agent. Install the agent you want to use first and sign in to it, following that agent's own instructions. BunnyCode will then start it for you.

You'll also want [Git](https://git-scm.com/downloads) installed to use the git features.
